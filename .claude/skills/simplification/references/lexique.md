# Lexique — des mots de pro, pas de jargon

Un club ou un organisateur n'est pas analyste. Chaque libellé se lit à voix
haute comme une phrase qu'il dirait. Traduire dans les trois langues
(clés i18n), tutoiement comme le reste de la Console.

| Jargon | Mot Yuno (FR) | Clé existante |
|---|---|---|
| Mix revenu | D'où vient le CA | `owner.an.revenueMix` |
| Settlement | Ce que tu touches | `owner.an.settlement` |
| ROI promoteurs | Ce que rapportent les promoteurs | `owner.an.promoterRoi` |
| ROI (court) | Rendement | `owner.an.promoterRoiShort` |
| Funnel / entonnoir de conversion | Du menu au paiement ; Visite → achat | `owner.an.drinksFunnel` |
| Audience | Abonnés | `anf.view.community.subscribers` |
| Comportement d'achat | Achats | `owner.an.purchaseTab` |
| Global | Vue d'ensemble | `anf.view.sales.overview` |
| RFM / segment RFM | Fidèles, à risque, perdus… (le nom du segment) | `rfm_segment` traduit |
| CTR | Taux de clic, ou « N clics sur M » | — |
| Conversion rate | « N % des visiteurs ont acheté » | — |
| Churn | Clients qui décrochent | — |
| Cohorte | Venus pour la première fois en … | — |

Questions-titres de référence (`anf.q.*`) : « Combien ai-je vendu ? »,
« Comment se vend cette soirée ? », « Qui vend pour moi ? », « Est-ce qu'on
me voit ? », « Qui sont mes clients ? ».

Règles d'écriture :
- Un nombre suivi de ce qu'il compte : « 112 inscrits », pas « 112 ».
- Une définition ⓘ = UNE phrase qui dit ce qui est compté et ce qui ne l'est
  pas (« remboursements déduits », « seuls les visiteurs consentants »).
- Un pourcentage sur une petite base se remplace par le compte brut.
- Pas de « Yuno Pro » pour la Console, pas de « panel », « cockpit »,
  « app organisateur » (voir `CLAUDE.md`).
